# Prompt for: Marketing Intern - Task 2 (Create a Landing Page)

The judges score COMMUNICATION, STRUCTURE, FLOW and PERSUASION, not design skill.
So the words and the order of the page matter more than fancy visuals or animation.

Step 0: Pick ONE: Run Club / Content Creator Kit / Everyday Tote Bag.
Step 1: Fill the [brackets] and paste into Antigravity (Planning mode). Skills must be in .agent/skills.

---
I'm a marketing intern candidate. Task: create ONE landing page for: [CHOSEN OFFER, e.g. "Run Club - Start Running in 30 Days"].

The page is judged on communication, structure, flow and persuasion (not design skill). It must:
- explain clearly why someone should care
- remove doubts a first-time visitor may have
- build interest and trust with simple, relatable words
- guide the visitor from curiosity -> understanding -> action
- make the value obvious and the call-to-action (CTA) feel natural

Work in this order and name the skill you use at each step. Stop and wait for my OK after steps 1 and 2.

1. product-marketing + customer-research: Define the target user, their main problem, fears and hopes. Give me a short summary.
2. offers + marketing-psychology + cro: Propose the page structure (section by section) and the ONE action we want (the CTA). Explain why each section is in that order.
3. copywriting: Write all the words: headline, sub-headline, benefits, how it works, FAQ that answers doubts, trust element, final CTA. Simple, friendly language.
4. copy-editing: Tighten the words. Remove jargon and filler.
5. frontend-design + frontend-ui-engineering: Build it as one clean, mobile-friendly HTML page. Keep the design simple and readable. No heavy animation.
6. web-design-guidelines + accessibility + cro: Review the finished page, list problems, fix them.
7. Write my 3-5 line explanation: (a) who the target user is, (b) what action I want them to take, (c) how the page is designed to drive that action.

Use placeholder images only if I don't provide any. Don't invent fake statistics or fake reviews.
---

Delivering it: the task accepts a PDF or a shareable link. Ask Antigravity at the end:
"Help me turn this page into a PDF" or "Help me publish this page to get a shareable link."
